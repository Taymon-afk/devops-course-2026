# Работа с Git в VS Code и терминале

## Три удобства VS Code

1. Во вкладке **Source Control** видно, какие файлы изменены. Можно проверить их перед коммитом.
2. VS Code подсвечивает добавленные и удалённые строки. Так проще понять, что именно изменилось в файле.
3. Файлы можно добавить в коммит и отправить изменения на GitHub через интерфейс, не вводя команды вручную.

## Одно преимущество терминала

Терминал позволяет точно управлять Git с помощью команд. Например, `git status` быстро показывает текущую ветку и состояние файлов.

# Сравнение Git и SVN

1. **Почему ветвление в Git «дешёвое», а в SVN — «дорогое»?**  
   В Git ветка — это указатель на коммит, поэтому её создание быстрое и почти не требует места. В SVN ветка создаётся как копия каталога в репозитории. Само копирование SVN выполняет эффективно, но работа с такими ветками и их слияние обычно сложнее.

2. **Можно ли сделать коммит в SVN без интернета? Почему?**  
   Обычно нет: SVN отправляет коммит сразу в центральный репозиторий, поэтому нужно соединение с сервером. Без соединения можно редактировать файлы локально, а закоммитить изменения позже.

3. **Когда SVN может быть предпочтительнее Git?**  
   SVN может подойти организации с уже настроенной централизованной инфраструктурой, которой нужен единый сервер и разграничение доступа к отдельным каталогам репозитория.
